# ProstoKVN Network v0.22.0

Релиз посвящён надёжности, безопасности локальных настроек и дальнейшему разделению исходного кода на небольшие понятные модули.

## Изменения

- большой `core.py` разделён на `routing.py`, `node_tester.py`, `blocklists.py` и `vpn_runner.py`; сам `core.py` оставлен как совместимый фасад;
- игровой список процессов убран из ядра: пользователь может добавлять свои Windows-приложения для маршрутизации через VPN;
- стратегия `Games` переименована в `Приложения`, внутренний ключ сохранён для совместимости настроек;
- выбор лучшего узла больше не зависит от фиксированных игровых IP: используются несколько HTTPS-проверок, TCP, UDP, медианная задержка и показатель стабильности;
- временные логи тестирования узлов автоматически очищаются;
- реализованы несколько групп подписок с добавлением, редактированием, удалением и выбором активной группы;
- URL подписок шифруются Windows DPAPI перед записью в `settings.json`;
- настройки записываются атомарно через временный файл и резервную копию;
- автообновление дополнительно проверяет Authenticode-подпись загруженного EXE после SHA-256;
- добавлен watchdog VPN-процессов и опциональное автоматическое переподключение после неожиданного завершения ядра;
- статусная строка интерфейса показывает TUN и активное ядро вместо устаревшей строки локального mixed-порта;
- обработка темы и менеджер подписок вынесены из главного GUI в отдельные UI-модули;
- GitHub Actions запускает unit-тесты маршрутизации, парсеров узлов, настроек, подписок и updater перед сборкой EXE.

Публичный Windows-релиз по-прежнему публикуется только после успешной SignPath-подписи и проверки `Get-AuthenticodeSignature` со статусом `Valid`.
