# ProstoKVN Network v0.20.0

Полный ребрендинг приложения в **ProstoKVN Network**.

- Новый бренд ProstoKVN Network во всём интерфейсе и документации.
- EXE переименован в `ProstoKVNNetwork.exe`.
- Локальный каталог данных: `%LOCALAPPDATA%\ProstoKVN Network\`.
- TUN-интерфейс: `prostokvn_network_tun`.
- Сохранена автоматическая миграция настроек предыдущих версий.
- Автообновление через GitHub Releases с проверкой SHA-256.
- Автоматическая установка официальных sing-box и Xray-core при первом запуске.
- Менеджер групп подписок и автоматическое тестирование узлов.
- Стратегии Smart / Games / Global.
- Доменные зоны `.ru`, `.su` и `.рф` направляются напрямую.
- `Steam.exe` остаётся DIRECT.
- Маршрутизация Discord и Telegram сохранена.
