# Стиль кода ProstoKVN Network

Код проекта должен оставаться простым и читаемым.

- Небольшие функции с одной понятной задачей.
- Понятные имена без лишних сокращений.
- Константы приложения хранятся отдельно от GUI.
- Сетевую логику и автообновление не смешиваем с Tkinter-интерфейсом.
- Комментарии пишем только там, где без них неясно «почему», а не пересказываем строку кода.
- Комментарии в коде — на русском языке.
- Не добавляем абстракции «на будущее», пока для них нет реальной задачи.
- Перед коммитом проверяем `py_compile` для Python-файлов.
