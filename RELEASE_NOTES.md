# Smart VPN v0.19.0

Первый публичный релиз Smart VPN.

- Автоматическая проверка обновлений через GitHub Releases.
- Проверка SHA-256 перед установкой обновления.
- Автоматическая установка официальных sing-box и Xray-core при первом запуске.
- Менеджер групп подписок и автоматическое тестирование узлов.
- Стратегии Smart / Games / Global.
- Доменные зоны `.ru`, `.su` и `.рф` направляются напрямую.
- `Steam.exe` остаётся DIRECT.
- Улучшена маршрутизация Discord и Telegram.
- Обновлён и упрощён интерфейс.
- Пользовательские настройки хранятся отдельно в `%LOCALAPPDATA%\SmartVPN\` и не перезаписываются при обновлении.
