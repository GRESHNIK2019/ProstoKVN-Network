# ProstoKVN Network

ProstoKVN Network — open-source Windows-клиент для раздельной маршрутизации трафика через VPN. Приложение работает с несколькими группами подписок, проверяет доступные узлы и позволяет гибко управлять тем, какой трафик идёт через VPN, напрямую или блокируется.

## Возможности

- стратегии `Smart`, `Приложения` и `Global`;
- отдельный раздел **Настройки → Маршрутизация**;
- пользовательские правила для приложений, доменов и IP/подсетей;
- для каждого пользовательского правила доступны маршруты `VPN`, `DIRECT` и `BLOCK`;
- `.ru`, `.su` и `.рф` направляются напрямую встроенными правилами;
- отдельная маршрутизация Discord и Telegram, Steam остаётся DIRECT;
- пользовательские правила применяются с приоритетом над обычными встроенными правилами;
- системные процессы `sing-box`, `Xray` и самого ProstoKVN Network защищены от ошибочной маршрутизации в VPN-петлю;
- VLESS, VMess, Trojan, Shadowsocks, Hysteria2, TUIC и VLESS XHTTP/gRPC/WS/REALITY;
- несколько HTTPS-проверок, TCP/UDP и оценка стабильности при выборе узла;
- несколько групп подписок с выбором активной группы;
- URL подписок шифруются Windows DPAPI перед записью в настройки;
- атомарное сохранение `settings.json` и резервная копия;
- автоматическая установка официальных `sing-box` и `Xray-core`;
- watchdog VPN-процессов и автоматическое переподключение;
- светлая, тёмная и системная тема;
- проверка обновлений через GitHub Releases;
- проверка SHA-256 и Authenticode перед установкой обновления.

## Интерфейс

Главный экран **Серверы** предназначен только для работы с VPN-узлами:

- обновление и проверка узлов;
- выбор сервера;
- запуск и остановка VPN;
- просмотр протокола, задержки, UDP и состояния подключения.

Настройки маршрутизации вынесены отдельно в **Настройки → Маршрутизация**, чтобы управление серверами и правилами трафика не смешивалось в одном экране.

В окне **Настройки** доступны разделы:

- **Основные** — тема и автопереподключение;
- **Маршрутизация** — стратегия и пользовательские правила;
- **Ядра** — пути к `sing-box.exe` и `xray.exe`, установка/обновление ядер и списков.

## Маршрутизация

### Режимы

| Режим | Поведение |
|---|---|
| `Smart` | Использует встроенные smart-правила, списки маршрутизации и пользовательские правила. |
| `Приложения` | Через VPN идут выбранные приложения и предусмотренные встроенные сервисы, остальной трафик остаётся DIRECT. |
| `Global` | Почти весь трафик направляется через VPN, кроме защищённых DIRECT-правил. |

### Пользовательские правила

Можно создавать правила трёх типов:

- **Приложение** — например `TheCrewMotorfest.exe`;
- **Домен** — например `*.ubisoft.com` или `example.com`;
- **IP / подсеть** — например `203.0.113.15` или `192.168.0.0/16`.

Для каждого правила выбирается действие:

- `VPN` — направить через VPN;
- `DIRECT` — отправить напрямую;
- `BLOCK` — заблокировать соединение.

Пример:

```text
Steam.exe                  DIRECT
TheCrewMotorfest.exe       VPN
*.ubisoft.com              VPN
telemetry.example.com      BLOCK
192.168.0.0/16             DIRECT
```

Если VPN уже запущен, новые настройки можно применить кнопкой **Применить к VPN** — соединение будет перезапущено с обновлённой конфигурацией маршрутизации.

Старый список **Приложения VPN** автоматически мигрирует в новые правила формата `Приложение → VPN`.

## Как устроены правила

Маршрутизация формируется в `src/routing.py` и передаётся в рабочую конфигурацию `sing-box`.

В первую очередь защищаются системные процессы VPN-ядер и самого клиента, затем применяются пользовательские правила, после чего — встроенные правила выбранной стратегии и финальный маршрут режима.

Это позволяет, например, оставить `Steam.exe` напрямую, направить конкретную игру через VPN и отдельно заблокировать нежелательный домен.

## Структура проекта

- `src/` — исходный код и ресурсы приложения;
- `src/ProstoKVNNetwork.pyw` — основное окно и логика интерфейса;
- `src/routing.py` — TUN-правила, пользовательские правила и маршрутизация;
- `src/node_tester.py` — проверка и оценка узлов;
- `src/blocklists.py` — загрузка и кэш списков маршрутизации;
- `src/vpn_runner.py` — запуск и остановка sing-box/Xray;
- `src/ui/` — отдельные части интерфейса;
- `scripts/` — локальный запуск, проверка исходников и сборка;
- `tests/` — unit-тесты;
- `docs/` — правила разработки;
- `.github/workflows/build.yml` — Windows-сборка и SignPath pipeline;
- `CODE_SIGNING_POLICY.md` — правила публичной подписи;
- `PRIVACY.md` — политика конфиденциальности;
- `THIRD_PARTY.md` — сторонние компоненты.

## Запуск из исходников

```bat
scripts\start.bat
```

## Проверка исходников

```bat
python scripts\check_source.py
python -m unittest discover -s tests -p "test_*.py" -v
```

Проверка валидирует UTF-8, синтаксис Python, unit-тесты и совпадение версии между `version.json`, `src/app_config.py` и `src/version_info.txt`.

## Локальная сборка

```bat
scripts\build_exe.bat
```

Готовый файл появится в `dist\ProstoKVNNetwork.exe`.

## GitHub Actions и подпись

Каждый push в `main` собирает CI artifact. Официальный Release создаётся только из тега вида `vX.Y.Z`, если подключён SignPath и полученный EXE проходит проверку Authenticode.

До одобрения проекта SignPath Foundation публичная публикация подписанного EXE в workflow остаётся выключенной. Настройка описана в [`SIGNING.md`](SIGNING.md).

## Системные изменения

Во время работы VPN приложение создаёт TUN-интерфейс и временно изменяет маршрутизацию Windows. Ядра, настройки и служебные файлы хранятся в `%LOCALAPPDATA%\ProstoKVN Network\`.
