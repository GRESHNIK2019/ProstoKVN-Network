# Privacy Policy

ProstoKVN Network не содержит телеметрии, рекламных SDK и аналитики и не отправляет данные владельцу проекта.

## Что хранится локально

Приложение может хранить в `%LOCALAPPDATA%\ProstoKVN Network\`:

- URL подписки, указанный пользователем;
- выбранную тему и стратегию маршрутизации;
- скачанные ядра `sing-box` и `Xray-core`;
- кэш списков маршрутизации и служебные файлы.

## Сетевые обращения

При работе приложение может обращаться к следующим системам только для выполнения своих функций:

- к URL подписки, указанному пользователем;
- к GitHub API и GitHub Releases для проверки обновлений и загрузки официальных релизов зависимостей;
- к источникам открытых списков маршрутизации;
- к выбранному пользователем VPN-узлу;
- к адресам, которые пользователь открывает через настроенную маршрутизацию.

Проект не имеет собственного сервера сбора статистики и не получает историю посещений пользователя.

## Сторонние компоненты

Приложение использует или может загружать открытые компоненты `sing-box` и `Xray-core`. Их сетевое поведение определяется выбранной пользователем конфигурацией и правилами маршрутизации.

## Изменения системы

При запуске VPN создаётся TUN-интерфейс и изменяется таблица маршрутизации Windows. Это необходимо для работы VPN и действует во время активного подключения.
