# Third-party components

ProstoKVN Network является open-source проектом.

Во время работы приложение может скачивать официальные релизы следующих независимых open-source проектов:

- `SagerNet/sing-box`;
- `XTLS/Xray-core`.

Эти upstream-компоненты не подписываются сертификатом ProstoKVN Network. Они загружаются отдельно и сохраняют собственные лицензии и подписи/хеши, предоставленные их разработчиками.

Python-зависимости для сборки перечислены в `requirements.txt` внутри исходного архива проекта и устанавливаются GitHub Actions из публичных пакетов.
